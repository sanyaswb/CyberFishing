### Configuration and domain

- `game-domain` cannot import `game-config` or `game-config-raw`.
- `game-config-raw` has 0 allowed dependencies and therefore remains dependency-free.
- `game-config → game-domain` is limited to target roles: `domain-contract`, `value-object`.
- Configuration reaches domain through: `constructor-injection`, `factory`, `composition-root`.
- Domain concepts must be modeled as domain contracts/value objects, not disguised as raw configuration constants.

## Production and development graphs

- Production root: `entrypoint-game`.
- Production must not reach: `dev`, `bootstrap-development`, `entrypoint-dev`.
- Development root: `entrypoint-dev`; its graph must reach `dev`.
- Production layers never depend on development layers. Development may consume public production boundaries.

## Change workflow

2. Migrate one dependency cluster together with its focused tests and manifest update.

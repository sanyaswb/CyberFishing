# Spec 162 — Живець за видом (TK-229.3)

Статус: у роботі (2026-11-06). Задача власника — TK-229.3 у `tasks.md`; рішення власника записані там.

## Зміни в ігровому процесі (коротко)

1. **Риба, що підходить для живця (вага ≤ `liveBait.maxWeightKg`), стає живцем сама** при «Забрати» — з таймером
   життя. Окремого переведення («На живця» для улову, `convertStoredCatch`) немає. Збережений придатний улов
   переводиться в живців при завантаженні (таймер з цього моменту).
2. **Картка живця:** «На живця» — насадити на гачок; «В акваріум» — активна лише з купленим акваріумом (інакше
   неактивна); «Відпустити».
3. **Живець за видом:** вибір живця обирає його **вид**. Коли насаджений живець витрачено або він помер, наступним
   береться живець того ж виду з найменшим залишком життя (акваріумні без таймера — останні). Нема такого виду — вибір
   знімається.
4. **Світчер наживки:** обраний живець показується в комірці наживки зображенням low цього живця.
5. **Заміна наживки:** якщо на гачку вже є наживка — картка живця підсвічується зеленим, кнопка стає «Замінити», у
   світчері блимає зеленим доступна комірка (наявна логіка заміни наживки, docs/inventory-behavior.md). «Замінити»
   заміняє першу доступну комірку, або гравець натискає конкретну. Стара наживка повертається в рюкзак (лише коли
   снасть не у воді), живець насаджується.

## Модель

- `CatchDispositionService.resolve(..., "claim")`: придатна риба → `purpose: "live_bait"` з таймером.
- Збережений стан: `selectedSpeciesId` замість/поряд з `selectedFishId`; міграція схеми (`schemaVersion`), стара
  `selectedFishId` → її вид.
- `getSelectedBait()` повертає живця обраного виду з найменшим залишком життя.
- Світчер: `baitSlots` отримує живця як предмет комірки (зображення low); заміна — через наявний вибір комірки.

## Перевірки

- `live-bait-check`: автоматичний живець при «Забрати», міграція збереженого улову, вибір за видом і наступний з
  найменшим залишком, акваріум неактивний без покупки, заміна наживки (у воді — без повернення).
- Game-cycle без змін або перебазування з причиною (рішення власника).
- `docs/gameplay_backlog.md` — запис.

## Приймання власником

Улов ≤ 100 г стає живцем; «На живця» насаджує, «В акваріум» неактивна без акваріума; після витрати живця береться
наступний того ж виду; заміна наживки з підсвіткою й вибором комірки; зображення живця у світчері.

# Задачі: мобільні комірки-вкладки редактора

Основа: [spec.md](spec.md). Статус: план реалізації; жоден пункт ще не виконаний.
Область: лише portrait до 820 логічних px. Тап зберігає чинну дію комірки, свайп переглядає параметри.

## 1. Контракт вкладок і стан перегляду

- [ ] T001 Описати мінімальний read descriptor вкладки: стабільний ключ, тип (основна/комірка/лише
  параметри), предмет або placeholder, доступне ім'я, стан, попередження, чинна адреса дії за наявності.
  Джерела — `panel.assembly.root`, `sockets`, `parameterItems`; не копіювати writable gameplay-стан.
- [ ] T002 Додати presentation-resolver мобільних вкладок: основна першою, кожна адресна комірка
  окремо, решта вкладених параметрів без повтору тих самих предметів. Не групувати різні комірки
  за характеристиками; не змінювати desktop/saved-preview контракт чинного section resolver.
- [ ] T003 Визначити єдиного presentation-власника активного ключа та життєвого циклу перегляду:
  новий редактор → основна вкладка; оновлення → зберегти ключ; зникнення адреси → основна вкладка.
  Відокремити його від `selectedInstanceId`/`pickedSocketId`. За потреби адресних read descriptors
  розширити view model і normalizer разом, без вигаданих адрес та змін save.

Пояснення: чинні секції згруповані за однаковими характеристиками, а дії виконуються для конкретного
слота. Вкладка повинна зберігати адресу навіть тоді, коли предмет у ній замінили або зняли.

## 2. Мобільна композиція

- [ ] T004 Додати невеликий renderer/pager блоку комірок і параметрів. Підключити наявні item art,
  placeholders, parameter renderer та meters. Функціональні комірки залишаються кнопками чинних
  дій; основна вкладка не викликає команду спорядження.
- [ ] T005 У `InventoryAssemblyEditorRenderer` відокремити панель дій із фоном та панель прев'ю;
  у цільовій композиції замінити окрему сітку комірок і стос секцій новим блоком. Зберегти
  desktop/landscape композицію та особливі кроки `rodRemovalStep`.
- [ ] T006 Описати BEM-стилі й використати токени: висота `--inventory-socket-size`, квадратні
  комірки, єдина вкладка 50% ширини, панель параметрів 100%, суцільне з'єднання активної вкладки
  з панеллю, однорядкова горизонтальна прокрутка. Не додавати глобальний mobile reset або
  жорсткі кольори/геометрію з референсу.
- [ ] T007 У `modal.css` та `InventoryUI` прибрати нижні вкладки, їхній grid track і компенсаційний
  padding лише коли мобільний редактор видимий. Узгодити шаблон із фактичними дітьми контейнера,
  перевірити bounded height і досяжність останнього параметра. У видимому рюкзаку повертається
  звичайна навігація за робочим припущенням FR-01.

Пояснення: приховування панелі не повинно залишати порожню смугу, перекриття або кнопки, що
перехоплюють натискання. Активна сторінка скорочує висоту без втрати доступу до довгих параметрів.

## 3. Жести й чинні команди

- [ ] T008 Через `InventoryUiBootstrap` підключити `SwipePagerController` до панелі параметрів:
  попередня/наступна вкладка, зупинка на краях, короткий/вертикальний/cancel жест без перемикання.
  Під час свайпу не dispatch-ити жодних команд спорядження чи вибору.
- [ ] T009 Вимкнути section swipe під час видимого мобільного редактора; узгодити ignore rules,
  `touch-action` найближчих scroller і придушення кліку. Переповнений ряд підключити до спільного
  drag-scroll; його прокрутка не виконує команд і не дублює жест pager.
- [ ] T010 Зберегти tap callbacks поточних комірок із повною адресою. Перевірити відмінність
  equipment-слота вудилища, assembly-компонента та контексту вже обраного предмета для заміни.
  Вкладка лише параметрів не отримує фіктивного `ASSEMBLY_SOCKET_ACTIVATE`.
- [ ] T011 Повторно використати чинну availability/compatibility-модель для порожніх комірок.
  За наявності доступного сумісного предмета — чинний pick і сторінка «Предмети» рюкзака;
  за відсутності — `showWarning`/`UiHintRenderer` зверху без початку pick. Додати потрібний текст
  до presentation-каталогу, зберегти окремі причини блокування.
- [ ] T012 Узгодити оновлення/закриття/поворот екрана: збереження ключа, фокуса й прокрутки,
  автоматичне відкриття видимої частини ряду для активної вкладки, detach/dispose bindings.
  Перемикання режиму не повинно множити контролери або змінювати маршрути завершення команд.

Пояснення: зараз тап може зняти предмет. Завершальний клік після свайпу є суттєвою регресією,
а не лише візуальним дефектом. Наявний platform-контролер уже має механізм його придушення.

## 4. Доступність і документація

- [ ] T013 Додати доступні назви, поточний стан перегляду та зв'язок із панеллю, видимий focus,
  клавіатурний перегляд Left/Right/Home/End без команд і Enter/Space як тап. Підтримати reduced
  motion, чинну політику hover та масштабування поверхні нижче 320px.
- [ ] T014 Уточнити правило іконок замість постійних ідентифікаційних написів у `DESIGN_RULES.md`
  §8; описати нові стилі/власників у `docs/styles.md` і взаємодії у `docs/inventory-behavior.md`.
  Оновити застарілі UI-очікування для editor-under-tabs лише в межах нового контракту;
  історичні specs 089/090 не переписувати.

## 5. Перевірки реалізації

- [ ] T015 Додати focused перевірки read descriptors і UI: основна вкладка, одна 50%, різні
  адреси однакових предметів, вкладені `parameterItems`, порожні/locked комірки, довгий ряд,
  відсутність параметрів, збереження стану та видалення батьківської комірки.
- [ ] T016 Перевірити жести й інтеграцію команд: свайп лише переглядає; завершальний клік не діє;
  штатний тап знімає/відкриває компонент як раніше; вибір і заміна потрапляють у точну комірку;
  відсутній сумісний предмет дає верхню підказку без навігації. Зберегти кейси наживки/прикормки,
  обмежень снасті у воді, зняття вудилища, saved preview і нецільових розкладок.
- [ ] T017 Запустити focused UI/integration та CSS/UI checks, `npm run check:architecture`,
  `npm run check:quick`, `npm run check` (Full). Не послаблювати guards, whitelists або baselines;
  діагностувати будь-яку зміну game-cycle/save як небажану для цієї задачі.
- [ ] T018 Виконати browser smoke `index.html`/`dev.html`: фізичні 240/280/319 px з UI scale,
  320/360/390 px, portrait 820/821, вузький landscape, довгі параметри, hint, клавіатура,
  touch, reduced motion, повторні відкриття й зміна орієнтації. Візуальне приймання — власником.
  Якщо браузерна перевірка не виконана, явно зазначити це в результаті.
- [ ] T019 Прибрати створені тимчасові артефакти та виконати `npm run clean:artifacts`, якщо
  вони створювалися. Звірити scope diff з цією задачею й зберегти сторонні незавершені зміни.

Залежності: T001–T003 → T004–T007 → T008–T012 → T013–T014 → T015–T019.
Focused регресії для кожного етапу додавати разом із відповідною зміною, а не відкладати
виявлення помилок до загального прогону. Реалізація, commit, release та публікація цим документом не виконуються.

# Spec 165 — Спорядження наживки: редактор завжди, підсвітка й спорядження паралельно (TK-242)

Статус: рішення власника записані (2026-11-07), реалізація не почата. Поглинає етап 3 spec 163 (живець у виборі наживки).

## Запит власника (2026-11-07, відповідь на TK-242)

«Зараз працює спорядження наживки неправильно.
1. Якщо комірка пуста і комірка для спорядження пуста — перший клік на наживку відкриває редактор. Що не так? При кліку на
   «Спорядити» повинна підсвітитися комірка, переключитися на «Екіпіровку» і підсвітити, чому я не можу спорядити.
2. Якщо комірка пуста і комірка для спорядження доступна — перший клік на наживку екіпірує її. Що не так? Паралельно
   повинен відкритися редактор обраної наживки.
3. Коли я спорядив наживку тип-1, то при кліку на наживку тип-2 відкривається редактор. Що не так? Я не можу замінити
   поточну наживку. Повинно працювати так: відкривається редактор, там з'являються кнопки «Замінити», «Назад»; паралельно
   підсвічується комірка у світчері, куди можна спорядити чи замінити, і при повторному кліку або кліку на конкретну
   комірку споряджається (заміняється) наживка на нову. Якщо комірок 2 і одна пуста — при повторному кліку споряджається
   пуста комірка.
4. Якщо я клікаю на пусту комірку у світчері — повинен відкритися фільтр «Сумісне» і підсвітитися доступні наживки. Що не
   так? Не підтягується наживка типу «живець», якщо присутня в інвентарі. При повторному кліку на пусту комірку, яка вже
   підсвічена, споряджається перша в списку автоматично, і автоматично відкривається фільтр «Усе».
5. Фільтр «Усе» не скидає фільтр наживки після вибору наживки.
Підсумок: при виборі наживки редактор відкривається завжди, паралельно працює підсвічування й екіпірування.»

## Рішення власника

- **B1. Немає куди спорядити** (немає гачка / комірки): клік — редактор наживки; «Спорядити» в редакторі переключає на
  «Екіпіровку» й підсвічує (тоном помилки) комірку, якої бракує, з поясненням.
- **B2. Є порожня комірка:** клік споряджає першу порожню й **паралельно** відкриває редактор цієї наживки.
- **B3. Усі комірки зайняті іншою наживкою:** клік відкриває редактор з «Замінити» й «Назад»; паралельно у світчері
  підсвічується комірка (комірки), куди можна замінити; повторний клік по наживці або клік по конкретній комірці
  споряджає (заміняє). Дві комірки, одна порожня — B2 (повторний клік заповнює порожню).
- **B4. Клік по порожній комірці світчера:** фільтр «Сумісне», підсвічені доступні наживки, **живці (стеки spec 163)
  теж**; повторний клік по тій самій підсвіченій комірці споряджає першу в списку й повертає фільтр «Усе».
- **B5.** Після вибору наживки «Усе» скидає підфільтр наживки (повний список).
- **B6. Підсумок:** вибір наживки завжди відкриває її редактор; підсвітка й спорядження працюють паралельно.
- TK-241 (та сама наживка вже на гачку → редактор) лишається окремим випадком B6.

## Рішення агента (технічні, на підтвердження під час етапу 1)

- **A1.** Один план кліку по наживці в `InventoryCommandService` (замість розгалужень `#activateConsumable`): ціль
  (порожня / та сама / інша / немає) → дія (спорядити / запропонувати заміну / нічого) + `showAssemblyEditor(bait)` завжди.
  Стан заміни — наявний `pickForConsumable(kind, socketId)` + `select(bait)`, тож підсвітка комірки світчера й повторний
  клік працюють як зараз, але редактор лишається відкритим.
- **A2.** Редактор наживки: дії залежать від стану — «Спорядити» (B1: при відмові `highlightSlot` з тоном помилки через
  наявний механізм підсвітки + переключення розділу), «Замінити» (B3: те саме, що повторний клік), «Назад».
- **A3.** B4: живець у «Сумісне» для комірки гачка — картка стеку (spec 163), вибір = «На живця» наступника виду через
  `LiveBaitHookController` (одна комірка, логіка «Замінити» spec 162); повторний клік по підсвіченій порожній комірці —
  перший кандидат списку (наявний `CONSUMABLE_SLOT_ACTIVATE` з кандидатом) + `selectCategory("all")` з очищенням
  підфільтрів (B5).
- **A4.** Перевірки на реальній композиції інвентаря: кожен із B1–B5 для черв'яка, хліба й живця; редактор відкритий
  паралельно зі станом підсвітки; повторний клік; дві комірки.

## Етапи

1. A1 + A2: B1, B2, B3, B6 для звичайних наживок.
2. B4, B5 + живець у виборі (A3) — колишній етап 3 spec 163.

## Приймання власником

Пункти 1–5 запиту на телефоні й ПК: редактор завжди відкривається, комірки світчера підсвічуються й заповнюються
паралельно, живець у «Сумісне», «Усе» після вибору показує все.
